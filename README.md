# 🌍 Мир Самозанятых v5.0

Платформа для самозанятых в России с ИИ-ассистентом, финансовым трекером, CRM, маркетплейсом, грантами и многим другим.

## ✨ Возможности

- 🤖 **ИИ Светлана** — персональный ассистент на базе OpenRouter
- 💰 **Финансовый трекер** — доходы, расходы, налоги, отчёты
- 🤝 **CRM** — управление клиентами и сделками
- 📅 **Календарь** — планирование встреч и задач
- 🛒 **Маркетплейс** — услуги самозанятых
- 🎁 **Гранты + AI** — подбор программ господдержки
- 📄 **Договоры** — генерация, подписание, QR-коды
- 📹 **Видеозвонки** — WebRTC-конференции
- 📊 **Аналитика** — графики, отчёты, экспорт
- 👥 **Реферальная программа** — 3 уровня
- 🏆 **Геймификация** — 10 достижений
- 🔐 **4 уровня подписок** — Free, Pro, Business, Enterprise
- 🎨 **White-label** — брендирование под свой бизнес
- 🌗 **Тёмная/светлая тема**
- 📱 **PWA** — работа как приложение
- 🔔 **Push-уведомления**

## 🚀 Быстрый старт

```bash
pip install -r requirements.txt
python server.py
```

## 🛠️ Технологии

- **Backend:** FastAPI + SQLAlchemy async + SQLite
- **Frontend:** HTML5 + CSS3 + Vanilla JS
- **AI:** OpenRouter API
- **Auth:** JWT + bcrypt + 2FA
- **Security:** CSP, rate limiting, audit log
- **DevOps:** Docker, Traefik, Let's Encrypt
