# Svetlana avatar assets

This directory is the single place for replaceable Svetlana avatar images.

## Files

- `svetlana-current.webp` — primary avatar used by the site.
- `svetlana-light.webp` — optional avatar variant for light theme.
- `svetlana-dark.webp` — optional avatar variant for dark theme.

The application should fall back to `svetlana-current.webp` when a theme-specific image is not present.

Recommended format: WebP, portrait/chest-up composition, transparent or clean background as appropriate for the design.

To replace Svetlana later, upload the new image files into this directory. Do not change template or CSS code just to replace the avatar.
